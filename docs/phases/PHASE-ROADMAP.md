# D'aMigo's — Phase Roadmap

| Phase | Timeline (target) | Goal |
|-------|-------------------|------|
| **P0 Foundation** | Weeks 1–3 | One kitchen internal E2E skeleton |
| **P1 MVP Pilot** | Weeks 4–10 | 10–15 Bangalore kitchens, real money |
| **P2 Density** | Weeks 11–20 | Analytics, hub, AI poster, WS hardening |
| **P3 Scale** | Weeks 21+ | Multi-city, optional per-order QR, dedicated WABA |

---

## Exit criteria

### P0 exit

- [ ] Admin can mint batch; owner activate
- [ ] Guest resolves scan → sees menu (manual menu OK)
- [ ] Cart + mock or test payment path
- [ ] CRM login + publish menu
- [ ] Traceability: all P0 features `Done` or `Deferred` documented

### P1 exit

- [ ] Razorpay live + Shiprocket quote on checkout
- [ ] Kitchen accept flow + guest track
- [ ] Rewards spin/claim + consents
- [ ] Kapso utility + marketing queue + 7-day cap enforced in code
- [ ] Wallet top-up ₹999 path
- [ ] Scan→order ≥ 8% in pilot cohort (metric)
- [ ] WARE ≥ 10 restaurants for 2 consecutive weeks

### P2 exit

- [ ] Hub live (curated)
- [ ] Dashboard analytics export
- [ ] Menu AI import ≥ 80% owner satisfaction (qual)
- [ ] WebSocket kitchen primary; poll fallback tested

### P3 exit

- [ ] Second city playbook documented
- [ ] 150+ WARE trajectory
